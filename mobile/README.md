# Ledger mobile

This folder is the future Expo app. It is a stub.

**Look at the mocks first.** They are the deliverable of this pass:

```bash
npm run mocks
```

Open [http://localhost:4173](http://localhost:4173). Read [`mocks/DIRECTIONS.md`](./mocks/DIRECTIONS.md).

When a direction is chosen, this package should become Expo Router talking to the existing `/api/month` and MCP contracts — same Neon database, no second store, INR and USD never converted. The Next.js web app in the repo root stays as the desk client.
